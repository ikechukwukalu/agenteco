Markdown holds the maintained content. Word is its ready-to-use document counterpart. Keep each pair aligned in the same pull request whenever content changes; preserve the approved headings, fields, categories and guidance. Render and inspect every Word page before delivery, and verify that no source content was omitted. Do not present an outdated Word copy as current or silently redesign an approved template.

These internal case documents do not define case statuses or authorize implementation, disciplinary action or case closure. Existing access, approval and review rules still apply.
